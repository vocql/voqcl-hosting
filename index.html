How it actually works

Click create, get a real server

A quick note first, because it matters: nothing lives on GitHub itself — GitHub can't run a live game server. What makes the button work is one real backend, hosted on a VPS, that we set up once. From then on, every click on this dashboard talks to that backend and it does the actual provisioning — you never see a terminal.

Configure

Pick your Minecraft version, server type (Vanilla, Paper, or Forge), and how much RAM to give it.

Hit create

The dashboard calls the backend directly. It starts a real Docker container running your server — no commands to copy or paste.

Get your address

The backend assigns a pre-set playit.gg tunnel address automatically, so it's ready the moment the container starts.

Saved automatically

The address lands straight in your dashboard, tied to your account — nothing to copy in by hand.

Before you start

The honest FAQ

Does this host the server for me?

The dashboard does — but it isn't magic, and it isn't free to run at scale. Behind the button is one real VPS running a small backend that starts Docker containers on your behalf. That backend is the actual "hosting" — the site just gives it a friendly front door.

Does the server stay online if I close my browser?

Yes — the container keeps running on the backend's VPS regardless of whether your browser or dashboard tab is open. It only goes offline if the backend stops it (e.g. you click "Stop & delete") or the VPS itself goes down.

Is playit.gg safe to use?

It's a widely used, free tunneling service built specifically for game servers. Traffic to your address is routed through their network — the same trade-off as any free tunnel, in exchange for not touching your router.
