How it actually works

No magic, just a script that does the boring parts

A quick note first, because it matters: nothing lives on GitHub itself. Your dashboard generates a command that runs on a computer you control — your own PC or a cheap VPS. That's what actually runs the server. We just make setting it up take two minutes instead of an afternoon.

Configure

Pick your Minecraft version, server type (Vanilla, Paper, or Forge), and how much RAM to give it.

Run one command

Copy the generated command into a terminal on your PC, a Raspberry Pi, or a $4/mo VPS. It installs Docker and the server for you.

Claim your tunnel

The script prints a one-time link from playit.gg — click it once to get a free public address, no router config needed.

Save & share

Paste the address into your dashboard. It's saved to your account, so you (and your friends) always know where to connect.

Before you start

The honest FAQ

Does this host the server for me?

No — and anyone who tells you a website can spin up a live game server for free with no machine behind it isn't being straight with you. You (or a $4/mo VPS) provide the machine; we generate the exact setup so it takes minutes, not hours.

Does my computer need to stay on?

Only while you want the server reachable. Close it, and it goes offline until you run docker start mc-server again — the dashboard saves that exact command for you.

Is playit.gg safe to use?

It's a widely used, free tunneling service built specifically for game servers. Traffic to your address is routed through their network — the same trade-off as any free tunnel, in exchange for not touching your router.
